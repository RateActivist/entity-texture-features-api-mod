# Entity Texture Features — ETF Override API

[![Download Latest](https://img.shields.io/github/v/release/RateActivist/entity-texture-features-api-mod?style=flat-square&label=Download&color=brightgreen)](https://github.com/RateActivist/entity-texture-features-api-mod/releases/latest)
[![Forge](https://img.shields.io/badge/Loader-Forge-orange?style=flat-square)](https://files.minecraftforge.net/)

Provides OptiFine-style random and emissive entity textures via resource packs without OptiFine.

## Features

- Random entity texture variants via resource packs
- Emissive texture overlay support for entities
- Blinking and player skin feature support
- Works alongside Entity Model Features perfectly
- Compatible with Sodium and Iris shaders

## Installation

1. Install [Minecraft Forge](https://files.minecraftforge.net/) for your Minecraft version
2. Download the JAR matching your exact Minecraft version above
3. Place the JAR into your `.minecraft/mods/` folder
4. Launch Minecraft with the Forge profile

- **Mod Loader:** Forge
